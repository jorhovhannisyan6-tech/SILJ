# SIL Insurance quotation template

The supplied customer quotation form is preserved here as the reference source:
- `SIL_Quotation_Template_Source.doc`
- `SIL_Quotation_Template_Source.docx` (converted reference copy)

The application renders a data-driven quotation in the same visual structure: cover page, general-information table, risk table, financial offer tables, service/claim procedure pages, and signature section.

The source template is reference-only; the web app does not modify the original file. Quote values are inserted from the application's deterministic calculation/proposal data.
