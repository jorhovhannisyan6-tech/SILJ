«ՍԻԼ ԻՆՇՈՒՐԱՆՍ» ԱՓԲԸ - ՀԻՓՈԹԵՔԱՅԻՆ (ԳՈՒՅՔԻ ԵՎ ԴԺԲԱԽՏ ՊԱՏԱՀԱՐՆԵՐԻՑ) ԱՊԱՀՈՎԱԳՐՈՒԹՅԱՆ ՊԱՅՄԱՆՆԵՐ

1. ՓԱԹԵԹՆԵՐ ԵՎ ԾԱԾԿՈՒՅԹ
1.1 PACKAGE I (Գույք + Կյանք / Դժբախտ պատահարներ) - Բանկերի մեծ մասի (Ամերիաբանկ, Էվոկաբանկ, Ակբա, ԱՐԱՐԱՏԲԱՆԿ, Հայբիզնեսբանկ և այլն) ստանդարտ պահանջ.
   - Գույքի ապահովագրություն. Անշարժ գույքի (բնակարան, առանձնատուն) վնասում կամ ոչնչացում հրդեհից, պայթյունից, ջրհեղեղից, երկրաշարժից և բնական աղետներից։
   - Վարկառուի/Համավարկառուի Դժբախտ պատահարներից ապահովագրություն. Վարկառուի մահվան կամ 1-ին/2-րդ խմբի հաշմանդամության դեպքում հիփոթեքային վարկի մնացորդի մարում SIL Insurance-ի կողմից։
1.2 PACKAGE II (Միայն Գույքի ապահովագրություն) - Գրավադրված բնակելի կամ կոմերցիոն անշարժ գույքի ապահովագրություն։

2. ԱՊԱՀՈՎԱԳՐԱԿԱՆ ԳՈՒՄԱՐ (SUM INSURED)
2.1 Ապահովագրական գումարը սահմանվում է Հիփոթեքային վարկի մայր գումարի մնացորդի + 2 տարվա տոկոսագումարների չափով (110-120% ծածկույթ), կամ գույքի շուկայական/գնահատված արժեքով։
2.2 Օգտատեր / Շահառու. Հիփոթեքային վարկ տրամադրած Ֆինանսական կազմակերպությունը (Բանկը) հանդիսանում է Առաջնային Շահառու (Beneficiary):

3. ԲԱՑԱՌՈՒԹՅՈՒՆՆԵՐ (EXCLUSIONS)
3.1 Անշարժ գույքի կոնստրուկտիվ վնասվածքներ առանց թույլտվության վերակառուցման պատճառով (ապօրինի քանդում, ապօրինի վերահատակագծում)։
3.2 Կանխամտածված վնասվածք կամ ապահովադրի/վարկառուի կոպիտ անպատասխանատվություն։
3.3 Վարկառուի մահ կամ հաշմանդամություն, որը հետևանք է մինչև պայմանագիրն առկա չարորոք ուռուցքային, սիրտ-անոթային կամ ծանր քրոնիկ հիվանդությունների (թաքցված հիվանդություններ)։
3.4 Ալկոհոլի, թմրանյութերի ազդեցության տակ ստացված վնասվածքներ կամ ինքնասպանություն։
