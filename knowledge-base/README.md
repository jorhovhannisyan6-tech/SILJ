# SIL Insurance AI Agent — պայմանների բազա

Այս պանակը պարունակում է օգտագործողի տրամադրած ապահովագրական պայմանները/նյութերը՝ որպես AI Agent-ի grounding աղբյուր։

## Աղբյուրների խմբավորում

- Գույք — `Գույք Պայմաններ.docx`
- Բեռներ — `Բեռի Պայմաններ.docx`
- Ընդհանուր պատասխանատվություն — `Ընդհանուր Պատասխանատվության պայմաներ.docx`
- Ինկասացիոն ռիսկ — `Ինկասացյոն Ռիսկ.docx`
- Կանխավճարի ապահովագրություն — երկու տրամադրված փաստաթուղթ
- Կապալառուի բոլոր ռիսկեր / Շինմոնտաժ — պայմաններ + թեստ + պատասխաններ
- Մասնագիտական պատասխանատվություն — համապատասխան պայմաններ
- Մեքենաների խափանում — համապատասխան պայմաններ
- Պահեստների պատասխանատվություն — հարցաթերթիկ
- ԿԱՍԿՈ — օգտագործողի տրամադրած Excel հաշվիչը պահված է որպես բնօրինակ աղբյուր

AI Agent-ը coverage/exclusion հարցերի դեպքում նախ ընտրում է համապատասխան աղբյուրները ըստ հարցի, այնուհետև դրանք փոխանցում է Gemini-ին որպես առաջնային grounding context։ Եթե աղբյուրը բավարար չէ, Agent-ը պետք է նշի, որ անհրաժեշտ է պայմանագրի/վկայագրի և դեպքի փաստաթղթերի ստուգում։
